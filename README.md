# Louvor

App Android de louvor, simples e com letras grandes, feito para pessoas idosas.
Baseado no [NewPipe](https://github.com/TeamNewPipe/NewPipe): sem anúncios, toca em segundo plano e baixa músicas.

- Botão grande **Falar** para buscar por voz
- Busca digitada e buscas rápidas (Adoração, Harpa Cristã, Louvores antigos…)
- Toda busca já procura por louvor
- Letras do app no mínimo 30% maiores

## Baixar

Abra a página **Releases** deste repositório e baixe o `Louvor.apk` mais recente.
